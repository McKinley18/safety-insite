4. THE ONE NON-STUB CREDENTIAL FOUND, AND WHY IT IS UNUSABLE
------------------------------------------------------------
  VERCEL_OIDC_TOKEN                  PRESENT -> **UNUSABLE (EXPIRED)**

  A Vercel OIDC token can authenticate Vercel AI Gateway, which would have been a
  genuine hosted-provider path, so it was evaluated rather than dismissed. Its own
  claims decide it. Non-sensitive claims only, identifiers reduced to lengths:

      iss          https://oidc.vercel.com/mckinley18s-projects
      scope        owner:<redacted>:project:safety-insite:environment:development
      environment  development
      aud          <39-char value, redacted>
      sub          <72-char value, redacted>
      owner_id     <29-char value, redacted>
      project_id   <32-char value, redacted>
      iat          1781750401
      exp          1781793601
      now          1788055244
      STATUS       EXPIRED by 1,739.35 hours (~72 days)

  Three independent reasons it is not the probe credential even setting expiry aside:

    (a) EXPIRED. A 12-hour build token, 72 days stale. It cannot authenticate anything.
    (b) MINTING A FRESH ONE IS AN UNAUTHORIZED ACT. `vercel env pull` is a Vercel
        account operation and rewrites `.env.local`, which is untracked user work.
        This operation is explicitly NOT authorized to make Vercel changes.
    (c) IT IS THE WRONG CREDENTIAL. It is scoped to the `safety-insite` FRONTEND
        project's development environment. It was provisioned for frontend builds,
        not for Expert HazLenz inference, and its AI Gateway balance and billing
        posture cannot be established from here -- so the hard spend ceiling of
        MAX_HOSTED_COST_USD = 3.00 could NOT be bounded before the first call.
        Phase 3 forbids a call whose maximum possible spend cannot be bounded.

  `vercel whoami` returns `mckinley18`, so the CLI IS authenticated. That is recorded
  as a fact and deliberately NOT used: CLI authentication is not a provider credential
  the owner provisioned for inference spend.
