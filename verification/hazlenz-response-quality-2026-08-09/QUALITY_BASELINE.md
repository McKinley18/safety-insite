# Baseline

The independently authored corpus contains 40 opaque scenarios. The first run produced 30 HTTP 201 responses and 10 HTTP 429 responses because the production classify endpoint enforces a 30-per-minute throttle. The 30 successful responses showed hazard recognition but frequent generic action projection; this transport artifact is tracked separately from reasoning metrics and is not treated as a quality pass.

Representative baseline defect: `permanentCorrectionNarrative` frequently read “Implement permanent engineered solutions specific to hazard,” while mechanism prose exposed internal identifiers. Cross-family action leakage was observed (a walking-surface case receiving electrical wiring correction).
