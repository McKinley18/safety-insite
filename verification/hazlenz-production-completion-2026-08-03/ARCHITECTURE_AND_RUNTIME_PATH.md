# Runtime path

The canonical path is authenticated `POST /safescope-v2/classify` → DTO validation and entitlement guard → SafeScope v2 service → evidence foundation/normalization → hazard and mechanism intelligence → jurisdiction and standards retrieval → applicability and ranking → clarification/evidence gaps → backend risk and corrective-action policy → persisted analysis snapshot and frontend guided-finding rendering.

The phase changed the evidence-foundation boundary only. It now carries normalized clarification answers into the evidence ledger, reevaluates the approved guarding predicate, and emits canonical visible standard-decision objects. Chemical-container, scaffold, and suspected-gas mechanism chains are evidence-aware and conservative.
