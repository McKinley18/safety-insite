# Independent evaluation plan

The previous 20-scenario authenticated evaluator is a production-path regression, not an independent release corpus. A separate corpus must keep expectations outside production code and score family applicability, jurisdiction, evidence discipline, negative controls, multi-hazard behavior, and corrective-action safety. The independent corpus was not completed in this pass because the authenticated entitlement harness produced false request failures and the full 100-case run could not be accepted without first repairing that harness. No PASS claim is made for an independent corpus.
