# Report integrity

Three reports were generated through the canonical completion workflow. Each has version 1, a distinct source inspection version 3, source fingerprint, storage object ID, byte length, and SHA-256. The owner download returned `application/pdf` and the stored bytes matched the recorded size/checksum. Reports were generated only after all current findings had reviews. A version-2/supersession change was not part of this phase and is explicitly unproven here.
