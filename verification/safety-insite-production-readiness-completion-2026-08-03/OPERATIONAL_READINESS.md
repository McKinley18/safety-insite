# Operational readiness

Deployment source documentation exists, but production readiness is incomplete without actual S3 provisioning, HTTPS/domain configuration, password-reset delivery, centralized logs/error monitoring, alerting, backups and restore rehearsal, incident response, data retention/export/deletion policy, and rollback rehearsal. The deployment checklist, runbook, release checklist, and rollback plan in this directory are explicit prerequisites, not proof of completion.
