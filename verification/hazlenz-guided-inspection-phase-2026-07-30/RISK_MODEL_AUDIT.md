# Risk model audit

The guided projection uses categorical severity, likelihood, exposure, overall risk, rationale, and provisional state. It does not manufacture a numeric score when material evidence is missing.

The reviewer can change all dimensions and supply a reason. The confirmed values are persisted in the human-review conclusion and drive corrective-action priority. Missing material predicates produce provisional language.

Residual limitations:

- Existing upstream risk services still contain more than one scoring vocabulary.
- The UI currently permits confirmation without an adjustment rationale even if a value was changed.
- Due-date policy is still a fixed seven-day workflow default; it is not yet a governed risk-to-SLA matrix.

Verdict: **READY WITH RESTRICTIONS** for qualified supervised review.
