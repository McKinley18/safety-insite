# Corrective-action audit

The guided contract separates:

1. immediate protective action
2. permanent correction
3. verification/closeout

It prefers existing grounded corrective reasoning and uses conservative hierarchy-of-controls fallbacks only when no structured action exists. It never asserts penalties or legal consequences. The reviewer edits each field before durable creation.

Risk affects urgency, and the final action plus verification task are server persisted before report completion.

Residual risk: the role/owner suggestion is advisory and the due-date default is not yet family-specific. Qualified review remains mandatory.
