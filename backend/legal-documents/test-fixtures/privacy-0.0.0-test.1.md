# TEST PRIVACY — NOT A LEGAL DOCUMENT

This document exists only to exercise the legal publication framework in automated tests. It is not
a privacy notice, it has not been reviewed by anyone, and it describes no real processing of any
real person's information.

## 1. Why this text exists

The acceptance matrix requires two independently versioned ACTIVE documents so that a test can show
Terms and Privacy are bound separately: a caller who supplies the right Terms version and the wrong
Privacy version must be refused on the Privacy one specifically.

## 2. What this text is not

It is not a notice, not a disclosure, and not a statement of any actual practice. No inference about
how the product handles information may be drawn from it.

## 3. A second version exists

`0.0.0-test.2` supersedes this version in the supersession fixture, which is how the test proves a
new version can replace an old one without rewriting an acceptance already recorded against it.
