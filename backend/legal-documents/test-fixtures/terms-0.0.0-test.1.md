# TEST TERMS — NOT A LEGAL DOCUMENT

This document exists only to exercise the legal publication framework in automated tests. It is not
Terms of Service, it has not been reviewed by anyone, and it confers and creates nothing.

## 1. Why this text exists

The ACTIVE publication path cannot be proven against an empty registry. Something has to be ACTIVE
for a test to show that the public route renders an exact version, that registration binds to that
version, and that a caller cannot substitute a different one. This is that something, and it is
written to be unmistakable if it ever appeared in front of a person.

## 2. What this text is not

It is not an agreement. It is not a policy. It creates no obligation on any party, grants no
licence, and describes no real processing of any real information.

## 3. Formatting exercised deliberately

A list, because the renderer has to handle one:

- an item
- a second item
- a third item

**Bold text** and *italic text*, because the renderer has to handle those too.

A link to [the product site](https://example.invalid/test), because link handling is the part of a
document renderer most likely to become an injection surface.
